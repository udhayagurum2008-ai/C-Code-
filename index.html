1. What is C?

C is a powerful general-purpose procedural programming language created by Dennis Ritchie in 1972 at Bell Labs. It is widely used for system programming, operating systems, compilers, and embedded hardware.

Key Features

High efficiency, low-level memory manipulation, structured programming, portability across platforms, and a simple core language syntax.

// Basic structure of a C Program
#include <stdio.h>

int main() {
    // C execution starts here
    return 0;
}

2. Syntax & Hello World

Every C program begins execution in the main() function. Header files like stdio.h provide standard input/output functions like printf().

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

3. Variables & Data Types

Variables store data values. C supports primitive types like int, float, double, and char.

#include <stdio.h>

int main() {
    int age = 25;
    float price = 19.99;
    char grade = 'A';
    
    printf("Age: %d, Price: %.2f, Grade: %c\n", age, price, grade);
    return 0;
}

4. Input & Output

The printf() function outputs data to standard output, while scanf() reads formatted input from the user using memory addresses (&).

#include <stdio.h>

int main() {
    int num;
    printf("Enter an integer: ");
    scanf("%d", &num);
    printf("You entered: %d\n", num);
    return 0;
}

5. Operators

C includes arithmetic (+ - * / %), relational (== != > <), and logical (&& || !) operators.

#include <stdio.h>

int main() {
    int a = 10, b = 3;
    printf("Sum: %d\n", a + b);
    printf("Remainder: %d\n", a % b);
    printf("Is Equal: %d\n", a == b);
    return 0;
}

6. Control Flow

Use if, else if, else, and switch statements to perform decision-making logic in C.

#include <stdio.h>

int main() {
    int score = 85;
    if (score >= 90) {
        printf("Grade A\n");
    } else if (score >= 80) {
        printf("Grade B\n");
    } else {
        printf("Grade C\n");
    }
    return 0;
}

7. Loops

Loops execute a block of statements repeatedly. Common loops are for, while, and do-while.

#include <stdio.h>

int main() {
    // For Loop
    for (int i = 1; i <= 5; i++) {
        printf("Count: %d\n", i);
    }
    return 0;
}

8. Functions

Functions divide code into reusable modular blocks. A function defines a return type, parameter list, and body.

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 7);
    printf("Result: %d\n", result);
    return 0;
}

9. Arrays

An array is a fixed-size sequential collection of elements of the same data type stored in contiguous memory locations.

#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    for (int i = 0; i < 5; i++) {
        printf("Element %d: %d\n", i, numbers[i]);
    }
    return 0;
}

10. Strings

In C, strings are arrays of characters terminated by a null character ('\0'). string.h provides utility functions like strlen() and strcpy().

#include <stdio.h>
#include <string.h>

int main() {
    char name[] = "C Code Lab";
    printf("Name: %s\n", name);
    printf("Length: %lu\n", strlen(name));
    return 0;
}

11. Structures

A structure (struct) allows grouping variables of different data types into a single custom compound type.

#include <stdio.h>

struct Student {
    int id;
    char name[50];
    float gpa;
};

int main() {
    struct Student s1 = {101, "Alice", 3.8};
    printf("Student %s (ID: %d) GPA: %.2f\n", s1.name, s1.id, s1.gpa);
    return 0;
}

12. Pointers

A pointer is a variable that stores the memory address of another variable. Use & to get an address and * to dereference.

#include <stdio.h>

int main() {
    int val = 42;
    int *ptr = &val;

    printf("Value: %d\n", val);
    printf("Address: %p\n", (void*)ptr);
    printf("Dereferenced: %d\n", *ptr);
    return 0;
}

About C

History & Overview

C was developed in 1972 by Dennis Ritchie at Bell Laboratories for the Unix operating system. It became one of the most widely adopted programming languages in computing history, directly influencing languages such as C++, Java, C#, and JavaScript.

Standard Libraries

C relies heavily on standard libraries: stdio.h (I/O operations), stdlib.h (memory allocation & utilities), string.h (string handling), and math.h (mathematical functions).
